 2 | ||| Interpolated strings are of the form `"xxxx \{ expr } yyyy"`.
 3 | ||| In this example the string `"xxxx "` is concatenated with `expr` and
 4 | ||| `" yyyy"`, since `expr` is not necessarily a string, the generated
 5 | ||| code looks like this:
 6 | ||| ```
 7 | ||| concat [interpolate "xxxx ", interpolate expr, interpolate " yyyy"]
 8 | ||| ```
 9 | ||| This allows to customise the interpolation behaviour by providing
10 | ||| an instance of `Interpolation` for a type.
11 | public export
12 | interface Interpolation a where
13 |   interpolate : a -> String
14 |
